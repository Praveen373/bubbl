<h1 align="center">Bubbl – Anonymous Chat</h1>
<p align="center"><b>Talk to a stranger. Stay one.</b></p>

Every bubble on your screen is a real person online right now. Tap one to chat. No sign-up, no phone number, no profile. Messages fade after 24 hours.

## Get it

- **Android:** [download the latest APK](https://github.com/Praveen373/bubbl/releases/latest/download/bubbl.apk), or see the install steps at [bubbl-chat.web.app/download](https://bubbl-chat.web.app/download)
- **iPhone, laptop, anything else:** [open Bubbl in your browser](https://bubbl-chat.web.app/app)

18+ only. Read the [privacy policy](https://bubbl-chat.web.app/privacy) and [community rules](https://bubbl-chat.web.app/terms).

## What's inside

- Physics-driven bubble sky: drag, fling and bump people around, shake to scatter
- Anonymous identities with random animal nicknames
- Real-time 1:1 chat with typing indicators and read receipts
- Report and block built in, with server-side rate limits
- Built with Expo, React Native, Reanimated and Firebase
